# Email_Sender

> Веб-приложение для автоматизации email-рассылок, управления клиентской базой и планирования отправки писем.

Система позволяет:

- создавать контакты вручную;
- импортировать контакты из CSV и XLSX;
- объединять контакты в группы;
- формировать рассылки для группы, отдельных контактов или их комбинации;
- отправлять рассылки сразу либо планировать их на заданную дату и время;
- отменять запланированные рассылки;
- отслеживать успешные и неуспешные отправки;
- управлять пользователями и данными через Django Admin.

## Основные возможности

### Пользователи и безопасность

- регистрация по имени пользователя, email и паролю;
- проверка уникальности email;
- минимальная длина пароля — 8 символов;
- вход по email и паролю;
- JWT-аутентификация с access- и refresh-токенами;
- обновление access-токена;
- выход с добавлением refresh-токена в blacklist;
- просмотр и изменение профиля;
- смена пароля;
- блокировка и разблокировка пользователей администратором;
- изоляция данных: пользователь получает доступ только к собственным объектам.

### Контакты и группы

- CRUD-операции для контактов;
- поиск, фильтрация и сортировка;
- импорт CSV/XLSX размером до 5 МБ;
- обязательные колонки импорта: `name`, `email`;
- необязательная колонка: `description`;
- проверка email;
- пропуск дубликатов в пределах одного владельца;
- импорт непосредственно в выбранную группу;
- отчёт по импорту: обработано, создано, пропущено, ошибки;
- CRUD-операции для групп контактов.

### Шаблоны писем

- создание, просмотр, редактирование и удаление шаблонов;
- хранение названия, темы и текста письма;
- поиск и сортировка шаблонов;
- повторное использование шаблона в нескольких рассылках.

### Рассылки

- выбор группы контактов;
- выбор отдельных контактов;
- одновременное использование группы и отдельных контактов;
- автоматическое удаление дубликатов получателей;
- немедленная отправка;
- отправка по расписанию;
- отмена запланированной рассылки;
- удаление только черновиков и отменённых рассылок;
- статусы: `draft`, `scheduled`, `processing`, `completed`, `completed_with_errors`, `failed`, `canceled`.

### История и статистика

- отдельный EmailLog для каждого получателя;
- сохранение текста ошибки;
- сохранение фактического времени отправки;
- поиск по email получателя и названию рассылки;
- фильтрация по статусу;
- пагинация истории;
- сводные счётчики успешных отправок, ошибок и запланированных рассылок.

## REST API

### Пользователи

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/register/` | регистрация |
| POST | `/login/` | вход и получение JWT |
| GET/PATCH/PUT | `/profile/` | профиль |
| POST | `/logout/` | выход |
| POST | `/change_password/` | смена пароля |
| POST | `/token/refresh/` | обновление access-токена |

### Администратор

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/profiles/` | список пользователей |
| GET | `/users/<id>/` | просмотр пользователя |
| PATCH/PUT | `/users/<id>/status/` | блокировка/разблокировка |
| DELETE | `/users/<id>/delete/` | удаление пользователя |

### Контакты, группы, шаблоны, рассылки и логи

Полный список эндпоинтов доступен в Swagger после запуска проекта.

- Swagger UI: `http://127.0.0.1:8000/api/docs/`
- OpenAPI schema: `http://127.0.0.1:8000/api/schema/`
- Django Admin: `http://127.0.0.1:8000/admin/`

## Запуск через Docker

### 1. Клонировать репозиторий

```bash
git clone <repository-url>
cd email-sender
```

### 2. Создать `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

### 3. Собрать и запустить контейнеры

```bash
docker compose up --build
```

### 4. Выполнить миграции

```bash
docker compose exec web python src/manage.py migrate
```

### 5. Создать администратора

```bash
docker compose exec web python src/manage.py createsuperuser
```

### 6. Открыть приложение

```text
http://127.0.0.1:8000/email_sender/home/
```

## Порядок работы пользователя

1. Зарегистрироваться и войти.
2. Создать контакты вручную или импортировать CSV/XLSX.
3. При необходимости объединить контакты в группу.
4. Создать шаблон письма.
5. Создать рассылку.
6. Выбрать группу и/или отдельных получателей.
7. Отправить сразу либо указать дату и время.
8. Просмотреть результат в статистике и истории отправок.

## Правила жизненного цикла рассылки

| Статус | Доступные действия |
|---|---|
| Черновик | изменить, отправить, удалить |
| Запланирована | изменить, отправить, отменить |
| Отправляется | ожидание завершения |
| Завершена | просмотр результата |
| Завершена с ошибками | просмотр результата |
| Ошибка | повторный запуск |
| Отменена | удалить |

## Административная панель

Админ-панель настроена для:

- поиска и фильтрации данных;
- управления пользователями и блокировкой аккаунтов;
- просмотра контактов, групп и шаблонов;
- запуска выбранных рассылок;
- просмотра статистики рассылок;
- неизменяемого аудита EmailLog.

Логи нельзя создавать, редактировать или удалять вручную через админку, чтобы сохранить достоверность истории.

## Ограничения текущей версии

- письма отправляются как текстовые сообщения;
- нет вложений; 
- SMTP-провайдер задаётся общими настройками проекта;
